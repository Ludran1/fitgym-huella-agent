==========================================================
 LECTOR DE HUELLA - PeakGym
==========================================================
Esta carpeta la dejo el instalador. No hace falta abrir ni tocar nada aca:
el programa arranca solo al iniciar sesion y se actualiza solo.

INSTALAR O REINSTALAR
  Ejecuta PeakGym-Lector-Setup.exe (se descarga desde PeakGym:
  Configuracion -> Integraciones -> Lector de huella).
  Si Windows avisa "Windows protegio su PC": "Mas informacion" ->
  "Ejecutar de todas formas".

VINCULAR CON TU GIMNASIO
  En PeakGym: Configuracion -> Integraciones -> Lector de huella ->
  "Vincular a este gimnasio". Sin esto las huellas no se guardan en la nube.

DESINSTALAR
  Configuracion de Windows -> Aplicaciones -> "PeakGym Lector de Huella".
  Las huellas y el vinculo quedan guardados por si lo volves a instalar.

LO UNICO QUE QUEDA A MANO (importante si el lector abre la puerta)
  Que Windows inicie sesion solo despues de un corte de luz. Sin esto, si se
  corta la luz un domingo, el programa no arranca hasta que alguien entre.
    Menu Inicio -> escribi  netplwiz  -> Enter
    Destilda "Los usuarios deben escribir su nombre y contrasena"
    -> Aceptar -> escribi la contrasena del usuario dos veces.

SI ALGO NO ANDA
  PeakGym muestra el estado del lector en la misma pantalla de Vincular.
  El registro del programa esta en:  http://localhost:8000/logs
